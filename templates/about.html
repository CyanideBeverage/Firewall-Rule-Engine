What This System Does

Firewall Rule Engine is a web-based cybersecurity simulation built to demonstrate how a stateless Layer 3 / Layer 4 packet-filtering firewall inspects and controls network traffic.

  • Packet Inspection: Evaluates simulated inbound and outbound packets by Source/Destination IP (including CIDR subnets), Ports, and Protocols (TCP, UDP, ICMP).
  • Priority-Based First-Match-Wins: Checks active rules in ascending priority order and applies the first matching ALLOW or DENY rule.
  • Configurable Default Policy: Falls back to DENY (Zero Trust) or ALLOW when no rule matches.
  • Security & Auditing: Uses salted password hashing, Flask session protection, parameterized SQL queries (preventing SQL Injection), and SIEM audit logs.
Educational Simulation: Safely simulates firewall logic without modifying your computer's OS firewall or blocking real network traffic.
